## 1. 연구 배경 및 필요성

전시 병력동원·수송은 국가 비상태세에서 후방 자원을 전방에 적시 투입하는 전략 축이다.
2020년대 안보환경 변화가 본 연구의 필요성을 강제한다(prompts-outputs/05·07):

- **장기소모전 양상**: 러-우 전쟁에서 철도망(Ukrzaliznytsia)이 도로 마비·제공권
  상실 속 국가 생명선으로 기능(500만 피난 후송, 수출입 철도 비중 40→75%, 피격
  선로 90% 수주일 내 복구). 반면 러시아 부분동원령은 행정·수송 붕괴로 수 주 지연.
  → 수송망 탄력성 = 전쟁지속능력의 핵심 변수임이 실증.
- **치명적 링크의 전술적 중력**: 안토니우카 철도교 HIMARS 타격→헤르손 철수,
  크림대교 138일 복구. 단일 결절점 차단이 전선 붕괴를 초도.
- **한국 구조취약성**: 예비군 반 이상 수도권 거주 vs 전방 부대 접적지 집중(공간적
  불일치); 한강 교량·경부/영동 산악 터널 등 초크포인트 다발; 전철화 철도의 전력계통
  의존. 인구절벽(현역 50만 이하)으로 예비전력 소집·전개 속도에 전적 의존.
- **현행 모형 노후화**: ~1995 KIDA 단편 기하분석·정적 지체상수 입력에 머물러
  정밀타격·도심정체·분산형 철도복원 등 동태 변수 예측 한계.

→ **OSM 실도로망 위 동적 복합운송 시뮬레이션 + ML 판단지원** 연구의 시의성 확보.

## 2. 선행연구 검토

### 2.1 앵커: 진학은·박승배·서창열 (2022)

"시뮬레이션을 활용한 전시 복합운송 의사결정방안 연구", 한국산학기술학회논문지
23(4):252–258(prompts-outputs/02). 본 연구의 가장 가까운 국내 선행연구.

- **방법론**: 6단계 의사결정프레임; ArcGIS 지형분석 + 군 도로평균속도표 연계;
  **ARENA 이산사건 시뮬레이션**; 출발지(보급단/탄약창)→ADC(지역분배소) 복합운송.
- **목적함수 차별**: 민간 비용최소화 배제, **총 수송소요시간 최소화 + 보급주기 내
  임무달성(완수율)** 설정 → 군사물류 특수성 반영. (본 연구 KPI 체계의 정당화 근거.)
- **핵심결과**: 육·해상 비중을 육상 중심(0:0) 조정 시 총소요시간 최소. 원인 = 항만
  하역능력 한계 + 연계 육상자산 부족 → **거점 병목 전이** 정량 규명.
- **한계**: (i) 중량 단일 적재제약(부피톤 미반영), (ii) 기상·도로파괴 등 동적 위협 배제.
  + (본 연구 관점) ArcGIS 정적 속도, 실시간 우회 미지원, ML 미결합.

## 3. 연구 갭 (Research Gap)

국내 군 수송 시뮬레이션 선행연구의 **공통 한계 4종**(prompts-outputs/02):

1. **정적 속도 고착화**: 도로평균속도표/ArcGIS 기하평균 → 통행시간 정비례 추산.
   동적 흐름·BPR 저항 미반영.
2. **단일 제약/단편 연계**: 중량 중심 적재, 수단별 독립 분석. 환승 거점 병목 전이
   비연동.
3. **위협·인프라 붕괴 시나리오 부재**: 교량·터널 파괴 등 가혹 환경 결합 능력 결여.
   낙관적 정적 검증.
4. **실시간 의사결정 한계**: ARENA/AnyLogic 스케일↑ 시 NP-hard 연산지연 → 즉시
   대안경로 판단 불가.

**추가 갭(08 출력)**: 시뮬+ML+**자연어 판단요약** 엔드투엔드 결합은 사실상 공백.
기존은 시뮬 결과→ML 단방향 주입에 그치거나(LimSim++는 자차 미시안전에 한정),
추천결과의 인과를 자연어 브리핑하는 수준 미도달.

## 4. 연구 질문 및 목적

**주 질문(RQ)**: 다층 위협·복합운송·코리더 다변화 조건 하에서,
(a) bus-only 대안과 rail-bus(+sea/air 보조) 복합대안의 **시간·완수율·가중시간 KPI
차이**는 어떠하며, (b) 동적 우회와 ML(XGBoost/KMeans/SHAP)+자연어 판단요약이
지휘관 의사결정 지원에 어떻게 기여하는가?

**세부 질문**:
- RQ1: 위협사다리(L1~L4) 악화에 따른 KPI 민감도는 비선형적으로 붕괴하는가?
- RQ2: 치명적 링크(대관령터널 등) 차단 시 우회·수단전환(rail→diesel/sea)의 완충 효과 크기?
- RQ3: 코리더·집결지 다변화가 완수율 분산(리스크 헤징)에 기여하는가?
- RQ4: AI 판단요약이 (설명가능성 통해) 자동화 편향/거부·정보오염 탐지에 유효한가?

**목적**: 위 질문에 준실험적 답을 제공하는 의사결정지원 프레임 구축.

## 5. 연구 기여 (Contribution)

1. **OSM 동적 복합운송 CRN 시뮬레이션**: 실도로망 위 다수단(road/rail/sea/air)
   동적 흐름 + 실시간 우회(Dynamic Rerouting). 정적 속도모형 한계 극복.
2. **다층 위협사다리 정식화**: BPR 링크차단/용량감소/지연 3단계 + L1~L4 severity
   ladder. 위협 배제 한계 극복.
3. **코리더·집결지 다변화 실험**: 단일 코리더(송파→고성) → 5축·4집결지. 공간적
   불일치·리스크 집중 해소 근거 제공.
4. **시뮬+ML+자연어 판단요약 결합(research gap 해소)**: XGBoost(목표 4급 위험) +
   KMeans(상황군집) + SHAP(설명) 직렬 → 군사 자연어 판단요약. 실시간 의사결정
   가속 + 설명가능성(국방AI 3원칙) 동시 확보.
   > 현행 구현(Phase 1) = XGBoost **4급 라벨규칙** + feature_importance + **KMeans** +
   > **SHAP**(optional) + **자연어요약**. `ml_baseline_v1.json`(macro-F1 0.887)은 stub 영향 baseline.

## 6. 연구 방법론 개요

- **데이터플로우**: region spec(YAML) → OSM 그래프(GraphML cache, 오프라인 기본) →
  `build_simulator_graph()` DiGraph → `run_scenario()` → KPI dict.
- **CRN 짝실험**: bus-only vs multimodal 동일 seed 블록 → delta를 수송구조 탓으로
  귀속(노이즈 분리).
- **결정론적 within-scenario**: `force_deterministic=True`. 분산원은 탐색적
  Morris 파라미터(road_noise_sigma/turnaround_noise_lambda, 기본 0)만.
- **KPI**: makespan $M=\max_i t_i$; completion_rate $C=\frac1N\sum I(t_i\le T_{target})$;
  penalized $P=\max_i t_i+\sum_{j\in M_{miss}}w_jD_j$.
- **AI layer**(목표 파이프라인): 시뮬 출력 → XGBoost 4급 분류 → KMeans 군집 → SHAP → 자연어 요약.
  현행 = XGBoost **3급** + feature_importance(`results/ml_baseline_v1.json`, Phase 7 확장).
- **위협 매핑**: disruption 시나리오 CSV(capacity_factor/p_fail_scale/max_edges +
  패밀리) ↔ 위협사다리 레벨.
- **보안/오프라인**: 공개 행정중심·공용망 only; live OSM은 opt-in.

(구현 상태·격차는 `03_실험재설계안.md` §6)

## 7. 기대효과·한계·연구경계

**기대효과**: 치명적 링크·거점 병목 사전 식별; 코리더·수단 다변화에 따른 완수율
분산 효과 정량화; ML+설명가능성으로 지휘관 인지부하 경감; 국방AI 3원칙(설명·신뢰·통제)
준거 사례 제공.

**한계(명시)**:
- 파라미터는 공개 통계·교리 기반 **추정치/가정**(속도·용량·헤드웨이·환승·응소율·censoring).
  현장 검증(calibrated) 아님.
- 단일 표본 규모(~1,000명, 1 부대) 국한; 다중 부대 동시동원 미모사.
- sea/air 보조축은 조건부·확률적 활성화로 보수적 가정.
- 민간 피난 수요와의 도로 경합 양방향 모델은 향후 과제.

**claim 경계**: 결과는 의사결정지원·민감도 분석으로만 해석. 운용계획·예측·최적경로·
검증·최종완료 표현 금지. `final_study_ready=false` 유지.
