# KCI 재설계 통합 산출물 (kci_redesign/)

`prompts-outputs/`의 8개 deep-research 결과를 통합한 산출물 묶음.
목적: 단일 코리더(bus-vs-rail) 시뮬레이션을 **KCI 게재 수준의 연구 프레임**으로
재구성하고, 교리·위협·수단·지리 근거로 **실험을 재설계**하는 제안서.

> **Claim discipline.** 본 묶음의 모든 수치는 "준실험적(quasi-real) 의사결정지원"
> 목적의 **가정·추정치**. "운용계획/예측/검증/최적경로/최종완료" 표현 금지.
> `final_study_ready=false` 원칙 유지. 출처 없는 단정은 배제.

## 파일 구성

| 파일 | 내용 | 주요 근거 출력 |
|---|---|---|
| `01_연구보고서.md` | 한국어 연구보고서 — 서론(시의성)·동원수송 교리·위협체계·재설계 개요 | 01·05·07·03 |
| `02_KCI프레임.md` | KCI 논문 프레임 — 배경·선행연구·연구갭·연구질문·기여·방법론·한계 | 02·08 |
| `03_실험재설계안.md` | 실험재설계 — 복수집결지·복합운송 4수단·다층위협사다리·코리더 5개 다변화·KPI 정당화·설계 매트릭스·구현 격차 | 01·03·04·06·07 |

## 사용법

1. `02_KCI프레임.md` → 논문 서론/관련연구/연구방법 초안 베이스.
2. `03_실험재설계안.md` → 코드 구현 로드맵(`src/realworld/regions.py`,
   `policy_alternatives.py`, `disruption_scenarios.py`, `pilot_experiments.py`,
   `ml_analysis.py` 매핑 포함).
3. `01_연구보고서.md` → 국방AI 공모/보고서용 한국어 전개.

- **01 동원소집 교리** → 거점체계·시간통제·KPI 의미 (보고서·재설계안)
- **02 선행연구 KCI** → 진학은(2022) 앵커·9논문·연구갭 (KCI프레임)
- **03 위협/장애** → 6범주·P×C·다층 위협사다리·BPR 3단계 (재설계안)
- **04 수단별 용량** → 4수단 파라미터·환승비용 (재설계안)

- **06 지리/동원축** → 5코리더·치명적링크·SIM-COR 매트릭스 (재설계안)
