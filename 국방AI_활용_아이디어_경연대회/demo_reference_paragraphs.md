# 데모 참조 문단 초안

작성일: 2026-05-13

이 문서는 확정된 웹 데모 URL과 스크린샷을 보고서에 삽입하기 위한 문단 초안이다.

## 1. 본문 삽입 문단

본 제안의 구현 가능성을 설명하기 위해 공개자료 기반 비작전 웹 데모를 함께 구성하였다. 데모는 서울/수서권 집결 및 철도 접근에서 평택지제 환승권과 평택 지원 권역으로 이어지는 단일 예시 시나리오를 사용한다. 화면은 버스 단독 수송과 철도-버스 복합 수송을 같은 조건에서 비교하고, 완료시간·성공률·도로 차량 서비스 시간 등 샘플 KPI를 표시한다. 표시된 지도와 수치는 실제 배치 지침이나 운송 명령이 아니라, 장애·혼잡·환승 불확실성 아래에서 대안별 위험을 비교하는 의사결정 지원 프로토타입의 예시이다.

## 2. URL 문장

데모 URL: `https://webdemo-fawn.vercel.app`

위 URL은 심사자가 화면 구조와 의사결정 지원 흐름을 확인하기 위한 시연 링크이며, 실제 운용 체계 또는 최종 승인 산출물이 아니다.

## 3. 그림 캡션 초안

- 그림 1. 서울/수서-평택지제 축 공개자료 기반 비작전 대안 비교 데모 화면.
- 그림 2. 버스 단독과 철도-버스 복합 수송의 샘플 KPI 비교 화면.
- 그림 3. evidence boundary와 formal acceptance 미완료 상태를 함께 표시한 검토 화면.
