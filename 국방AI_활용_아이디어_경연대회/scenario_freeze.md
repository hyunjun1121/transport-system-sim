# 시나리오 동결 메모

작성일: 2026-05-13

## 1. 동결 시나리오

이번 경연대회 제출물과 웹 데모는 다음 하나의 시나리오만 사용한다.

> 서울/수서권 집결 및 철도 환승 접근 축에서 평택지제역 및 평택 지원 권역으로 향하는 공공데이터 기반 비상 수송 의사결정 지원 시나리오

## 2. 공간 표현

| 구분 | 보고서/웹 데모 표현 | 금지 표현 |
|---|---|---|
| 출발 권역 | 서울/수서권 집결 권역, 수서권 집결지 | 실제 부대 집결지, 세부 정문, 실제 집결 절차 |
| 철도 접근 | 수서 철도 접근점, 수서 Rail Access Hub | 실제 승차 지시, 실제 탑승 시간표 |
| 도착 환승 | 평택지제 환승권, Pyeongtaek-Jije Transfer Area | 실제 하차 명령, 세부 후속 배차 |
| 목적 권역 | 평택 지원 권역, Pyeongtaek Support Zone | 특정 군사시설, 보안시설, 실제 목적지 |
| 도로 보조점 | Road Contingency Waypoint | 실제 우회도로 지시, 세부 작전 동선 |

## 3. 비교 대안

- `bus_only`: 도로 중심 단일 수송 대안 샘플
- `multimodal` 또는 `rail-bus`: 수서권 철도 접근과 평택지제 환승을 포함한 복합 수송 대안 샘플

두 대안은 같은 조건에서 비교하는 시뮬레이션 샘플이며, 어느 대안이 항상 우월하다는 결론을 내리지 않는다.

## 4. 허용 메시지

- 공개자료 기반 비작전 모의 예시
- 대안별 위험과 병목을 비교하는 의사결정 지원
- 버스 단독과 철도-버스 복합 수송의 tradeoff 제시
- 훈련·사전 검토·참모 판단 보조용 프로토타입
- 추가 검증과 보안 검토가 필요한 연구 데모

## 5. 금지 메시지

- 실제 작전 명령
- 최적 경로 또는 최종 배치안
- 실제 배차 지시 또는 실시간 통제
- 실제 소요시간 보장
- 현장 적용 가능성이 검증 완료되었다는 표현
- 현재 웹 데모 또는 시뮬레이션 결과를 최종 승인 증거로 해석하는 표현

## 6. 완료 기준

- 웹 데모, 보고서, 스크린샷 캡션이 모두 같은 시나리오명을 사용한다.
- 다른 지역 축이나 다른 실증 시나리오를 추가하지 않는다.
- 지명은 권역 수준으로 유지하고, 민감 시설명은 쓰지 않는다.
