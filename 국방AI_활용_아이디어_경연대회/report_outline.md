# 보고서 구조 초안

작성일: 2026-05-13

## 제목

AI 기반 비상 수송 의사결정 지원 시뮬레이션

## 1. 제안 배경 및 목적

- 비상 상황에서는 도로 장애, 교통 혼잡, 집결 지연, 차량 회차 제약, 환승 지연이 동시에 발생할 수 있다.
- 단일 경로 또는 단일 수단 중심 검토는 불확실성 아래에서 어떤 대안이 더 취약한지 설명하기 어렵다.
- 본 제안은 공개 교통망과 시뮬레이션 AI를 활용해 버스 단독과 철도-버스 복합 수송 대안을 사전에 비교하는 의사결정 지원 체계를 제안한다.
- 목적은 실제 명령 자동화가 아니라 지휘관·참모가 대안별 병목, 미수송 위험, 지연 위험을 빠르게 비교하도록 돕는 것이다.

## 2. 아이디어 요약

- 입력: 공개 도로망, 철도 환승 축, 수요 규모 예시, 차량·환승 가정, 장애 시나리오
- 처리: 반복 시뮬레이션, 대안 비교, 병목 탐지, 민감도 분석
- 출력: 완료시간, 성공률, 미수송 위험, 도로 서비스 시간, 대안별 취약 조건, 지도 기반 요약
- 대표 시나리오: 서울/수서권 집결 및 철도 접근에서 평택지제역과 평택 지원 권역으로 이동하는 단일 비작전 예시

## 3. 상세 내용

1. 데이터 계층
   - 공개 도로망, 철도역, 행정 권역 자료를 시뮬레이션 그래프와 권역 라벨로 변환한다.
   - 민감 위치는 배제하고, 권역 수준 라벨만 사용한다.

2. 시뮬레이션 계층
   - 도로 혼잡, 링크 장애, 지연 도착, 차량 회차, 환승 시간을 반영한다.
   - 버스 단독과 철도-버스 복합 대안을 같은 조건에서 반복 비교한다.

3. AI 분석 계층
   - 대안별 병목과 취약 변수를 요약한다.
   - LLM은 결과 설명과 보고서 초안 보조에 제한하고, 핵심 판단은 재현 가능한 수치 산출물에 둔다.

4. 의사결정 화면
   - 지도, 표, KPI, evidence boundary 패널로 결과를 표시한다.
   - 데모 URL과 스크린샷은 비작전 모의 예시로만 제시한다.

## 4. 차별성

- 일반 길찾기처럼 단일 최단 경로를 추천하지 않고, 불확실성 아래의 대안별 취약 조건을 비교한다.
- 생성형 AI 단독 답변이 아니라 시뮬레이션, 민감도 분석, 공통난수 비교, 결과 설명을 결합한다.
- 공개자료 기반 MVP에서 출발해 향후 비식별 내부 자료와 폐쇄망 검증으로 확장할 수 있다.
- 군 수송뿐 아니라 재난대응, 지자체 비상 수송, 공공기관 훈련 시나리오에도 확장 가능하다.

## 5. 실현 가능성

- 현재 저장소는 버스 단독과 철도-버스 복합 수송을 비교하는 Python 시뮬레이션과 React 웹 데모 구조를 갖는다.
- 웹 데모는 Vercel에 배포 가능한 Vite 앱이며, 공개자료 기반 단일 시나리오를 시각화할 수 있다.
- 초기 단계는 공개자료와 예시 파라미터로 구성하고, 이후 검증 단계에서 공식 데이터와 비식별 내부 자료를 분리해 반영한다.

## 6. 적용 효과성

- 제한된 시간 안에 복수 수송 대안을 비교할 수 있다.
- 병목 구간과 민감 변수를 사전에 식별해 훈련과 계획 검토의 근거를 제공할 수 있다.
- 반복 가능한 실험 로그와 대시보드를 통해 의사결정 근거를 설명할 수 있다.
- 지역 템플릿화가 가능해 전군 또는 공공부문 비상 수송 검토에 재사용할 수 있다.

## 7. 추진 전략

1. 0~3개월: 공개자료 기반 단일 시나리오 MVP와 웹 데모 정리
2. 3~6개월: 대안 비교 KPI, 보고서 자동 요약, 스크린샷 기반 설명 자료 구성
3. 6~12개월: 검증용 데이터와 비교, 비식별 내부 자료 연계 가능성 검토
4. 12개월 이후: 폐쇄망 적용, 지역별 템플릿화, 훈련 평가 체계 연계

## 8. 한계 및 안전장치

- 본 제안은 실제 작전 명령 또는 배차 지시가 아니다.
- 현재 수치는 데모 샘플이며 최종 승인 증거가 아니다.
- 공식 적용 전에는 데이터 검증, 보안 검토, 현장 전문가 검토, 재현성 검증이 필요하다.
