# 2. 아이디어 개요

## 1) 제안 배경 및 목적

국방 수송 의사결정은 빠른 판단이 필요하지만, 단일 경로를 고르는 문제로만 볼 수 없다. 도로 장애, 교통 혼잡, 집결 지연, 차량 회차 제약, 철도 환승 가능성, 말단 이동 제약이 동시에 작동하기 때문이다. 이런 상황에서 하나의 경로 또는 하나의 수단만 검토하면, 장애가 발생했을 때 어떤 조건에서 실패 위험이 커지는지 판단하기 어렵다.

본 제안은 공공데이터와 시뮬레이션 AI를 활용해 비상 수송 대안을 사전에 비교하는 의사결정 지원 체계를 제안한다. 목적은 실제 작전 명령이나 배차 지시를 자동으로 생성하는 것이 아니라, 지휘관과 참모가 제한된 시간 안에 대안별 병목, 지연 위험, 미수송 위험, 취약 파라미터를 정량적으로 비교하도록 돕는 것이다.

대표 시나리오는 서울/수서권 집결 및 철도 접근 축에서 평택지제역 및 평택 지원 권역으로 향하는 공공데이터 기반 비상 수송 의사결정 지원 시나리오로 고정한다. 수서역과 평택지제역은 공개적으로 확인 가능한 철도 환승 거점으로 사용하고, 목적지는 특정 시설이 아니라 넓은 "평택 지원 권역"으로 표현한다. 따라서 본 시나리오는 실제 집결 명령, 실제 배치안, 실제 이동 지시가 아니라 의사결정 지원용 비작전 모의 예시이다.

## 2) 아이디어 요약

본 아이디어는 지역 교통망, 철도 환승 축, 수송 수요 예시, 차량·환승 가정, 장애 시나리오를 입력받아 버스 단독 수송과 철도-버스 복합 수송을 같은 조건에서 비교하는 AI 기반 의사결정 지원 시뮬레이터이다.

시스템은 반복 시뮬레이션을 통해 완료시간, 성공률, 미수송 인원, 도로 차량 서비스 시간, 병목 조건을 계산한다. 결과는 지도, 표, KPI 카드, 짧은 자연어 요약으로 제공된다. AI는 결과 설명과 취약 변수 요약을 보조하지만, 핵심 판단은 생성형 AI의 단독 답변이 아니라 재현 가능한 시뮬레이션 산출물, 민감도 분석, 근거 로그에 기반한다.

본 제안의 핵심은 "최적 경로 하나를 자동 지시하는 체계"가 아니라 "불확실성 아래 여러 수송 대안의 위험과 성과를 비교하는 체계"이다. 이를 통해 참모는 제한된 시간 안에 어떤 대안이 도로 장애에 취약한지, 환승 지연이 어느 수준부터 문제가 되는지, 차량 회차 제약이 전체 완료시간에 어떤 영향을 주는지 검토할 수 있다.

# 3. 세부 기획안

## 1) 아이디어 상세내용

### 가. 데이터 계층

데이터 계층은 공개 도로망, 철도역, 행정 권역 자료를 그래프와 권역 라벨로 변환한다. 민감 시설이나 실제 작전 지점은 표시하지 않고, "서울/수서권", "수서 철도 접근점", "평택지제 환승권", "평택 지원 권역"처럼 넓은 표현을 사용한다.

프로토타입에서는 공개자료 기반 권역 좌표와 시뮬레이션 설정값을 사용한다. 실제 군 내부 자료는 초기 단계에 연결하지 않는다. 향후 적용 단계에서는 비식별·집계 자료, 폐쇄망 환경, 보안 검토 절차를 거쳐 별도 검증한다.

### 나. 시뮬레이션 계층

시뮬레이션 계층은 도로 혼잡, 링크 장애, 집결 지연, 차량 회차, 환승 시간을 반영한다. 같은 난수 조건에서 버스 단독 수송과 철도-버스 복합 수송을 반복 실행해 대안별 차이를 비교한다.

현재 구현체는 Python 기반 시뮬레이션 구조와 React 기반 웹 데모로 구성되어 있다. 버스 단독과 철도-버스 복합 대안을 비교하고, 지도·KPI·샘플 데이터 표·evidence boundary를 표시한다. 현재 수치는 최종 승인 결과가 아니라 프로토타입 샘플 결과이다.

### 다. AI 분석 계층

AI 분석 계층은 다음 기능을 담당한다.

- 예측 및 예지: 장애 강도, 집결 지연, 환승 지연에 따른 완료시간과 성공률 변화 추정
- 최적화: 출발 정책, 차량 배분, 복합수단 조합의 후보 비교
- 이상 징후 탐지: 특정 장애 조건에서 실패율이나 지연이 급증하는 조건 탐지
- 시계열 분석: 도착 지연, 차량 회차, 혼잡 누적의 시간 흐름 분석
- 정보 시각화: 정책별 KPI, 병목 구간, 취약 변수, 증거 경계를 지도와 표로 표시
- LLM 기반 설명 보조: 결과를 자연어로 요약하되, 수치 산출 권한과 작전 명령 권한은 갖지 않음

### 라. 의사결정 지원 계층

결과는 단일 정답이나 자동 명령이 아니라 대안별 비교표로 제시한다. 지휘관과 참모는 임무 우선순위에 따라 시간 최소화, 미수송 위험 최소화, 도로 부담 완화, 환승 리스크 회피 등을 비교할 수 있다.

웹 데모는 다음 URL에서 확인할 수 있다.

`https://defense-ai-mobility-demo.vercel.app`

데모 화면은 서울/수서-평택지제 축의 공개자료 기반 비작전 예시를 표시한다. 기본 언어는 한국어이며, 상단 토글로 영어 화면을 확인할 수 있다. 지도와 수치는 실제 작전 경로, 실제 배차표, 실제 소요시간 예측이 아니라, 대안별 위험 비교와 의사결정 지원 흐름을 보여주기 위한 샘플이다.

보고서 삽입용 스크린샷 파일은 다음과 같다.

- `demo_screenshots/demo_desktop_map_ko.png`: 한국어 기본 대표 지도 화면
- `demo_screenshots/demo_mobile_map_ko.png`: 한국어 모바일 반응형 확인 화면

- `demo_screenshots/demo_evidence_review_ko.png`: 한국어 evidence boundary와 formal acceptance 미완료 상태 검토 화면

## 2) 차별성

본 아이디어는 일반 길찾기나 단순 대시보드와 다르다. 일반 길찾기는 현재 조건에서 하나의 경로를 제시하는 데 강하지만, 국방·재난 수송 의사결정은 장애 가능성, 지연 도착, 차량 제약, 환승 불확실성을 함께 비교해야 한다. 본 제안은 단일 최단 경로가 아니라 여러 정책의 실패 조건과 병목을 비교한다.

또한 생성형 AI가 임의로 답을 만드는 구조가 아니다. 시뮬레이션 결과와 근거 로그를 먼저 만들고, AI는 이를 요약하고 설명하는 보조 역할을 한다. 따라서 판단 근거를 재검토할 수 있고, 향후 폐쇄망·비식별 데이터와 결합하는 단계적 확장이 가능하다.

기존 방식이 정태적 계획이나 경험 기반 판단에 의존하기 쉽다면, 본 제안은 같은 조건에서 여러 대안을 반복 비교하고, 장애·혼잡·환승 불확실성에 따른 성능 변화를 수치와 화면으로 제시한다. 이 점이 신속하고 정확한 의사결정 지원이라는 경연대회 주제와 직접 연결된다.

## 3) 실현 가능성

실현 가능성은 세 단계로 나누어 확보한다.

첫째, 공개자료 기반 MVP이다. 공개 교통망, 공개 철도역 정보, 권역 수준 지도 라벨, 예시 파라미터만으로 비작전 훈련·기획용 시뮬레이션을 수행한다. 이 단계에서는 민감 데이터가 없더라도 대안 비교 흐름을 구현할 수 있다.

둘째, 검증 가능한 시뮬레이션 파이프라인이다. 현재 프로젝트는 Python 기반 실험 구조, 공통 난수 기반 정책 비교, 샘플 결과 생성, React/Vercel 기반 시각화 구조를 갖추고 있다. 웹 데모는 Vercel production URL로 배포되었고, lint/build 검증과 스크린샷 캡처를 수행했다.

셋째, 폐쇄망·비식별 데이터 확장이다. 실제 적용 전에는 데이터 검증, 보안 검토, 현장 전문가 검토, 재현성 검증이 필요하다. 군 내부 자료는 초기 공개 데모에 연결하지 않고, 비식별·집계 자료와 폐쇄망 검토 절차를 통해 단계적으로 연계한다.

현행 법령·제도 측면에서는 본 제안이 자동 명령, 자동 배차, 실시간 작전 통제 체계가 아니라 참모 검토와 훈련용 의사결정 지원 도구라는 점이 중요하다. 따라서 초기 단계는 공개자료 기반 교육·훈련·사전 검토용으로 제한하고, 실무 적용은 별도 보안·법무·현장 검증을 통과한 뒤 추진한다.

## 4) 적용 효과성

본 체계는 제한된 시간 안에 복수 수송 대안을 비교하도록 돕는다. 참모는 완료시간뿐 아니라 미수송 위험, 도로 서비스 부담, 환승 지연, 병목 구간을 함께 볼 수 있다. 이를 통해 훈련 시나리오 검토, 사전 계획 검토, 재난·비상 수송 계획의 대안 비교에 활용할 수 있다.

군 실효성은 세 가지 측면에서 기대된다.

첫째, 의사결정 속도 향상이다. 여러 대안을 수작업으로 비교하는 대신, 동일 조건에서 반복 실험한 결과를 표와 지도 형태로 확인할 수 있다.

둘째, 위험 발견 능력 향상이다. 특정 경로가 막혔을 때 전체 완료시간이 얼마나 늘어나는지, 환승 지연이 어느 수준부터 병목이 되는지, 차량 회차 제약이 미수송 위험을 키우는지를 사전에 볼 수 있다.

셋째, 전군 확산 가능성이다. 특정 지역에 고정된 시스템이 아니라 공개 교통망과 권역 라벨을 바꾸면 다른 훈련·재난·지원 수송 권역에도 재사용할 수 있는 템플릿형 구조이다.

## 5) 추진 전략

1단계(0~3개월)는 공개자료 기반 단일 시나리오 MVP이다. 서울/수서-평택지제 축의 데모 지도와 샘플 KPI를 정리하고, 경연대회 제출물과 시연 URL을 구성한다.

2단계(3~6개월)는 대안 비교 대시보드 고도화이다. 정책별 KPI, 병목 요약, 민감도 분석, 보고서 자동 요약, 증거 로그를 강화한다.

3단계(6~12개월)는 검증과 보안 검토이다. 실제 운용 자료를 바로 연결하지 않고, 비식별·집계 자료와 폐쇄망 검토 절차를 통해 단계적으로 검증한다.

4단계(12개월 이후)는 지역 템플릿화이다. 동일한 분석 절차를 다른 훈련·재난·지원 수송 권역에도 적용할 수 있도록 입력 데이터 구조와 검증 절차를 표준화한다.

예상 제약은 데이터 신뢰성, 보안 민감성, 실제 운용 검증 부족, 현장 절차와의 연계이다. 대응 방안은 공개자료 기반 MVP와 실제 운용 검증을 명확히 분리하고, 모든 결과를 "의사결정 지원"과 "사전 검토"로만 사용하며, 최종 적용 전 전문가 검토와 보안 검토를 의무화하는 것이다.
