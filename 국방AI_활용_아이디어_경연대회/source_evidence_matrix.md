# 출처 및 증거 행렬

작성일: 2026-05-13

이 문서는 보고서와 웹 데모에서 사용할 수 있는 공식 출처, 내부 산출물, 가정값을 분리한다. 출처 없는 값은 본문에서 단정하지 않고 "예시 가정" 또는 "시뮬레이션 설정값"으로만 사용한다.

## 3. 내부 구현 근거

| 항목 | 저장소 근거 | 사용 방식 | 한계 |
|---|---|---|---|
| 시뮬레이션 샘플 | `web_demo/public/data/phase1_results.csv` | 버스 단독과 철도-버스 복합 수송의 makespan, success rate, service minutes 샘플 표시 | 최종 검증 결과가 아니라 데모 샘플 |
| 시나리오 구성 | `web_demo/public/data/config.yaml` | 노드, 도로 링크, 철도 링크의 데모 구성 | 실제 지도망 또는 공식 운영망 아님 |
| 지도 UI | `web_demo/src/components/map/OperationalMap.tsx` | 권역 라벨과 경로선 시각화 | 실제 작전 경로 지시가 아님 |
| 데이터 UI | `web_demo/src/components/panels/DataWorkspace.tsx` | 샘플 결과 표와 KPI 표시 | acceptance evidence가 아님 |

## 4. 가정값과 보류값

| 값 | 분류 | 처리 규칙 |
|---|---|---|
| 인원 1,000명 | 시뮬레이션 설정값 | "예시 수요 규모"로만 표기 |
| 차량 수, 열차 수, 환승 지연 | 시뮬레이션 설정값 | 실제 운용 능력으로 단정하지 않음 |
| 노드 좌표 | 공개 권역 기반 예시 좌표 | 정확한 시설 위치 또는 실제 집결지로 설명하지 않음 |
| makespan, service minutes | 샘플 결과 | "sample", "demo", "scaffold" 문구와 함께 사용 |
| formal acceptance 상태 | 내부 감사 상태 | 최종 승인 증거가 아니라 한계 조건으로만 사용 |

## 5. 주장 안전 규칙

- 공식 출처에서 확인된 내용만 단정형으로 쓴다.
- 내부 시뮬레이션 값은 프로토타입 샘플로만 쓴다.
- 좌표와 경로는 권역 수준 예시로 설명한다.
- 실제 수송 지시, 작전계획, 시간표, 배차표로 읽히는 표현은 삭제한다.
