## 1. 검토 대상

- `web_demo/` 지도와 대시보드 문구
- `지원서식_국방AI_활용_아이디어_경연대회.txt`
- 경연대회 보고서 초안 문장
- 데모 URL 및 스크린샷 캡션
- 출처 및 증거 행렬

## 2. 금지 표현 목록

다음 표현은 최종 제출물에서 사용하지 않는다.

- 실제 작전 명령
- 최종 배치안
- 자동 배차 지시
- 실시간 전장 통제
- 검증 완료된 작전 체계
- 실제 소요시간 보장
- 최적 경로 확정
- 특정 부대 또는 보안시설을 암시하는 목적지

## 3. 권장 대체 표현

| 위험 표현 | 대체 표현 |

| 작전 적용 | 훈련·사전 검토 적용 가능성 |
| 자동 배치 | 의사결정 지원 |

## 4. 현재 반영 상태

- 웹 데모 지도는 권역 라벨을 사용하도록 갱신했다.
- 대시보드 문구는 "sample", "non-operational", "not a final recommendation" 계열로 조정했다.
- 보고서 계획은 Vercel URL과 스크린샷 확정 전 데모 문단을 최종화하지 않도록 지정했다.
- 제출 양식 TXT는 실제 작전 명령, 자동 배차, 최종 승인, 현장 성능 보장 표현을 부정문 또는 한계 문구로만 사용하도록 작성했다.
- 출처 행렬은 공식 출처, 내부 샘플, 가정값을 분리했다.
- Vercel production alias는 `https://defense-ai-mobility-demo.vercel.app`로 갱신했고, 스크린샷 매니페스트와 제출 양식에 같은 URL을 반영했다.
- 웹 데모 기본 언어는 한국어로 설정했으며, 한/영 전환은 화면 문구 전환용이다. 양쪽 언어 모두 비작전·비승인 경계를 유지한다.
