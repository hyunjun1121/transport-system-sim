# 전시 예비군 수송 — 심층조사 프롬프트 묶음

## 목적
이 프로젝트(transport-system-sim)를 **KCI 학술논문 프레임**으로 재구성하고, 현재의 단순한
"수도권(잠실) → 강원도 전방 부대" 단일 코리더 실험을 **국방적으로 현실적이고 다변화된
실험설계**로 재설계하기 위한 근거자료 수집.

현재 프레임의 한계: 국방적 맥락이 단순함(집결지 1개, 수단 bus vs rail 2종, 위협 1축).
실제 전시 동원수송은 **복수 집결지 · 철도/육상/해상/항공 복합운송 · 다층 위협사다리 ·
시간임계성** 을 가짐. 이를 메울 조사가 필요.

## 사용법
1. 각 `NN_*.txt` 파일의 내용을 deep research 도구(또는 유사 검색에이전트)에 그대로 입력.
2. 한국군 조사이므로 **한국어로 질문·답변**. 한국 공식 출처(law.go.kr, 국방부, 병무청,
   국군수송사령부, 국방연구원(KIDA), KCI 학술지, 국방일보) 우선.
3. 산출된 답변을 본 프로젝트 디렉터리로 돌려주면 → Claude가 통합하여
   (a) KCI 논문 프레임(연구배경·선행연구·연구갭·연구질문·기여), (b) 실험재설계안으로
   정리.

## 주의 (프롬프트 공통)
- **보안/민감정보 금지**: 실제 부대 위치·편제·이동세부일정 등 군사보안사항은 요구하지 않음.
  공개 행정중심 좌표·공식 교리·공개 법령·학술논문 수준에서만 조사.
- 모든 수치·주장은 **출처(법령명/조문, 논문 저자-연도-저널, 보고서명, 언론사-일자)** 명시.
- KCI 인용가능 학술논문을 최우선.
