# 전시 동원예비군 수송대안 분석·판단지원 체계: 연구보고서

> 준실험적(quasi-real) 의사결정지원 시뮬레이션 프레임의 재구성 보고서.
> 단일 코리더·2수단(bus vs rail) 기반 현 시뮬레이션을 교리·위협·수단·지리 근거로
> **다코리더·복합운송·다층 위협사다리** 체계로 재설계하는 근거를 정리.
> 모든 수치는 가정·추정치이며 운용계획이 아님.

---

## 1. 서론: 연구의 시의성

현대전이 단기 결전에서 **장기소모전**으로 양상이 바뀌면서, 후방 인적·물적 자원을
전방으로 적시 투입하는 **동원수송망의 탄력성**이 전략적 중심으로 재부상했다
(prompts-outputs/05).

- **인구절벽**: 평시 현역 상비군 50만 명 이하 감소 → 유사시 국토방위 전력 형성이
  예비전력 소집·전개 속도에 전적 의존. 예비군 총원 약 273만(2022) 중 병력동원
  자원이 압도적 비중(prompts-outputs/07).
- **위협 고도화**: 북한 정밀타격·장사정포·EMP·드론이 한강 교량·터널·철도 변전소
  등 핵심 물류 인프라를 상시 마비시킬 수 있는 환경(prompts-outputs/03·05).
- **전례의 검증**: 우크라이나 국영철도(Ukrzaliznytsia)가 도로 마비·제공권 상실 속에서
  500만 명 피난 후송과 서방 군수 물류(수출입 철도 비중 40→75%)를 동시에 처리하며
  **철도망 복원력**이 국가 생존축임을 입증. 반면 러시아 2022 부분동원령(30만)은
  행정·수송 붕괴로 수 주 전개 지연(prompts-outputs/05). 안토니우카 철도교 HIMARS
  타격→헤르손 철수, 크림대교 138일 복구 등 **치명적 링크 차단이 전선 붕괴를 초래**한
  사례 다수.

**함의**: 한국 동원수송은 (i) 고밀도 수도권 집중→초크포인트 다발, (ii) 예비군 반
  이상 수도권 거주 vs 전방 부대 접적지 집중의 **공간적 불일치**, (iii) 전철화 철도의
  전력계통 의존 등 구조적 취약성 보유. 그럼에도 현행 모형은 ~30년 전 단편적
  기하분석에 머물러 동태 변수 예측에 한계. → 디지털 트윈 기반 동적 시뮬레이션 연구의
  시의성 확보(prompts-outputs/05).

## 2. 동원수송 교리 체계 (사실관계)

### 2.1 법정 절차와 시간 체계

- 동원령: **총동원(M)** vs **부분동원(PM)** 이원화. 병무청장 책임 하 지방병무청이
  소집통지서 집행(prompts-outputs/01).
- **자원지정 4유형**: 부대단위·집단·전국단위·권역화. 손실변수(기피·불합격·재해) 흡수
  위해 기본 120%, 동원사단·보충대대 등 특수임무는 **130%** 초과 지정(prompts-outputs/01·07).
- **시간체계** (시뮬 cut-off 상수로 직결):

| 구분 | 도착 시한 | 비고 |
|---|---|---|
| 총동원 M+1일 | M+1일 14:00 | 선포 다음 날 지정 시각 |
| 부분동원 PM+20h | 선포 시각 기준 20시간 이내 | 경과시간 기준 강제약 |
| 발령지 인접 자원 | 6시간 이내 | |
| 육상 타지역 | 24시간 이내 | |
| 도서/어선 | 48시간 이내 | |
| 긴급 1·2·3단계 | M+36 / M+60 / M+84 시간 | 단계별 인도·인접 완료 |

(출처: prompts-outputs/01. 공개 병무청·국방부 예규/훈령 기반)

### 2.2 거점 체계 (노드-아크 그래프)

```
최초집결지 ─(소수 셔틀)─▶ 중간집결지 ─(철도/고속차량)─▶ 인도인접지 ─(최종진입)─▶ 소집부대
```

- **최초집결지**: 관공서·학교 운동장 등 대중교통 접근 양호지. 입영확인관 통제.
- **중간집결지**: 허브. 편대 조직·열차 연계 정렬. **집결지당 500~1,000명** 수용 상한.
- **인도인접지**: 신분 전환·무장화. 정상(서식 대조) / 간이(실물 head-count) 모드.
- **소집부대**: 증·창설, 무기수여. 지각·초과 인원은 보충대대로 우회 흡수(prompts-outputs/01).
- **집단수송 판정기준**: 출발지→소집부대 편도 실거리 **61km 이상**, 또는 60km 이하라도
  대중교통 연계 부실로 통제 시한 내 입영 곤란 시 → **집단수송 차량편(징발 버스) 무상 제공**.
  60km 이하 정상 연계 = 개별입영(여비 정산). 원거리 자원의 도로망 의존도를 가르는 핵심
  임계값이며, 시뮬 집결→집단수송 전환 조건으로 직결(prompts-outputs/01; 병무청 공개 안내).

### 2.3 국군수송사령부 수단 분담

합참 지도·조정 하 **연합수송이동본부(CTMC)** 운영. 4수단 연계:
**철도**(장거리 주력, 호국훈련 시 디젤 전환훈련) · **육상**(말단 아크 전담, 민간
버스·트럭 징발, **차량 10대당 예비 1대**) · **해상**(도서 자원·상륙증원) ·
**항공**(긴급 공수·특수자원, 비중 <1%)(prompts-outputs/01·04).

### 2.4 병력 규모 정당화

본 시뮬레이션 기준 **~1,000명** = 예비군법 시행령 편제상 **대대(401~1,600명) 정중앙**,
즉 '완편 동원보충대대' 규모와 부합. 연대급(1,601~7,200) 슬림편성 해석도 가능.
→ 단일 표본 크기로 전술적 타당성 확보(prompts-outputs/07).

## 3. 전시 수송 위협 체계

### 3.1 6대 위협 범주

1. **인프라 파괴**: 교량(한강 11개 긴급복구대상)·터널·철도 전철화 설비.
   공병 LST 가설 40m→이틀, 70m→나흘(prompts-outputs/03).
2. **적 직접 타격**: 집결지·역·교차로·항만·공항. 우크라 크라마토르스크 역 피격 전례.
3. **WMD/특수**: 화생방 오염구역(Area Denial)·HEMP/NNEMP(신호·반도체 영구파괴).
4. **자연재해**: 강원 산악 집중호우·산사태·폭설. 우회로 제한적→단일 유실이 기하급수적 지연.
5. **사이버/C2**: 수송지휘통제망 DDoS·철도 CTC/LTE-R 교란(Fail-Safe 강제정지).
6. **수단 고장/자원고갈**: 차량·열차 고장, **유류 터미널 타격→배급제**, **운용요원 응소율 저하**(KIDA).

### 3.2 발생가능성×영향도 정량(추정)

| 위협 | P(E) | C(E) | S=P×C |
|---|---|---|---|
| 한강·남한강 교량 타격 | 4 | 5 | **20** |
| 터널/철도 전철화 파괴 | 4 | 4 | 16 |
| 집결지·역 타격 | 4 | 4 | 16 |
| C2/CTC 사이버 마비 | 4 | 4 | 16 |
| 유류고갈·운용인력 부족 | 4 | 4 | 16 |
| 강원 산악 자연재해 | 4 | 3 | 12 |
| HEMP/방사능 | 2 | 5 | 10 |

(prompts-outputs/03. P·C 1~5점 척도, S 1~25. 추정치)

### 3.3 BPR 3단계 장애 매핑 (시뮬 직결)

링크 통행시간 $t_e(x_e)=t_{e,0}[1+\alpha(x_e/C_e)^\beta]$ 기준:
- **링크 차단**: $C_e\to0$, 링크 제거($L'=L\setminus\{e\}$).
- **용량감소**: $C_e'=\gamma C_e$ ($0<\gamma<1$).
- **지연**: $t_{e,0}'=t_{e,0}+\Delta t_e$.

→ 현 시뮬레이션의 `capacity_factor`·`p_fail_scale`·`max_edges` 시나리오 인터페이스와
1:1 대응. **다층 위협사다리(재설계안 §3)**로 정식화.

## 4. 재설계 개요 (상세는 `03_실험재설계안.md`)

현 시뮬 = **단일 코리더(송파→고성) · 2수단(bus vs rail-bus) · 23정책×23시나리오×30 seed**.
구체 case(공개맥락): 송파권 집결 → 청량리역 연계버스 → 강릉역(KTX-이음, 현 복합안
**하차 기준점**) → 강원 고성 토성면 학야리 목적권역(공개 보도의 **제22보병사단** 맥락,
행정중심점 표식; 내부 시설 좌표 아님). 속초역·제진역은 미개통/건설·계획 맥락 → 향후
민감도 분석 후보로만 관리(기획서; 국가철도공단 2024).
교리·위협·지리 근거로 5축 확장 제안:

1. **복수 집결지**: 잠실(동부)·킨텍스(서북, 5t/㎡ 고하중)·수원메쎄(남부, 수원역 철도연계)·인천아시아드(서부).
2. **복합운송 4수단**: road + rail(KTX-이음; 전철마비→디젤전환) + sea(LST/Ro-Ro, **조건부**) + air(CN-235/C-130, **조건부·소수**).
3. **다층 위협사다리**: L1 국소 → L2 광역 다중 차단 → L3 철도통제불능+거점 → L4 총체 하이브리드 마비.
4. **코리더 다변화 5축**: 수도권→영동북부/영서내륙/경기북부접경, 영남권→동해안, 호남권→서해안접경.
   치명적링크: 대관령터널(21.7km)·인제양양터널(10.9km)·진부령/미시령·임진강교.
5. **KPI 정당화**: makespan(증·창설 완료 선포 시각) / completion_rate(데드라인 내 도달비) /
   penalized_makespan(미도착·핵심보직 지연 가중).

## 5. AI 판단지원 계층 차별성

"미시/거시 교통 시뮬레이션 + ML 위험분류 + **자연어 판단요약**" 엔드투엔드 결합은
**연구공백(research gap)** 영역으로 파악(prompts-outputs/08). 본 AI layer(Phase 1 구현):
- **XGBoost** 위험분류(4급 라벨규칙: 정상/주의/위험/실패위험)
- **KMeans** 상황군집(수천 노드→소수 전술 중심점 압축)
- **SHAP** 변수 공헌도(설명가능성, optional — shap 미설치 시 gain importance로 fallback)
- templated 생성 요약 → 군사 자연어 판단요약(OpOrd 초안 형태, claim-guard 통과)

> **현행 구현 상태(Phase 1 — `ml_analysis.py` + `results/ml_baseline_v1.json`)**: 상기
> 4종 전부 **Phase 1에서 구현 완료**. 단 (a) XGBoost **4급 라벨규칙**은 정의됐으나 실제
> populate 급 수는 입력 completion 분포에 의존, (b) SHAP은 optional(shap 미설치 시 gain
> fallback), (c) `ml_baseline_v1.json`(test macro-F1 0.887, 40 feature, leakage 경계 명시)은
> **Goseong graph-stub 영향 baseline**(`docs/validation_anchor.md` §3) — 실제 OSM 그래프
> 재실행 후 4급 populate + 수치 재측정 예정. 수치는 current-pipeline 측정치, 검증 모형 아님.

설명가능성 = 국방AI 전술적용 3원칙(설명·신뢰·통제 가능) 충족 근거. 지휘통제권·책임주의
보존, 자동화 편향/거부 방어, 정보오염(적대적 공격) 탐지에 기여(prompts-outputs/08).
