# Technical Summary

The current model appears to include:

- Directed graph transport network representation
- Edge attributes such as distance, speed, capacity, and base travel time
- BPR-style road travel-time correction with default parameters:
  - `alpha = 0.15`
  - `beta = 4.0`
- Rolling-window dynamic traffic-volume estimation
- Two disruption modes:
  - blocked
  - capacity_reduction
- Passenger waiting, boarding, and dispatch policies using STRICT and GRACE logic
- GRACE departure rules based on wait-time cap, arrival ratio, and vehicle capacity
- Multimodal routing using bus access, rail trunk movement, and last-mile shuttle
- Fixed-headway rail service
- Finite last-mile fleet, departure interval, turnaround time, and shuttle capacity
- Completion, censoring, delay, penalty, and arrival-time metrics
- Phase 1 / Phase 2 experiment design
- Common Random Numbers for policy comparison variance reduction

Do not assume this summary is complete or correct. Verify against the ZIP before relying on it.

# Evidence and Citation Rules

Use the ZIP contents as the primary evidence source.

Do not make file-specific or line-specific claims unless you inspected the relevant file.

- plausible risk
- inference
- recommendation

Inspect enough artifacts to answer the core request reliably.

Start with the main configuration, simulation modules, experiment scripts, audit outputs, and acceptance/evidence documents.

Inspect additional files only when needed to resolve a material uncertainty, verify a critical claim, or support a high-priority recommendation.

Stop inspecting once the core acceptance-readiness assessment can be supported with sufficient evidence.

- targeted smoke test
- deterministic seed check
- CRN pairing check
- audit script rerun
- cache integrity check
- representative experiment dry run
- output manifest verification

# Style

Write in English.

Do not overpraise. Do not speculate beyond the evidence.

Prefer concise sections and action-oriented recommendations.

Use tables only where they improve readability.
