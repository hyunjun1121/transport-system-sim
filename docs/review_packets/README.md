# Review Packet Index

## Scope

`docs/review_packets/` stores the 12 primary reviewer packet snapshots used by the
formal-blocker workflow. These files are consolidated review materials and are not a
replacement for formal acceptance artifacts.

Keep these as the canonical packet hub when sharing with human reviewers or
updating handoff summaries.

## Packet files

- `acceptance_review_index.md`
- `cached_osm_input.md`
- `data_provenance.md`
- `final_audit.md`
- `full_experiment_output.md`
- `graph_scale_strategy.md`
- `manuscript_report_alignment.md`
- `parameter_evidence.md`
- `pilot_region_accepted.md`
- `rail_evidence.md`
- `reproducibility.md`
- `sensitivity_analysis.md`
- `validation_package.md`

## Non-packet artifacts

The root `docs/` directory keeps gate-by-gate audit packets, package-level audits,
and scaffold/runbook materials. If a packet is updated, align the related manifest
and `data/validation/*_manifest.json` artifact in the same review cycle.
