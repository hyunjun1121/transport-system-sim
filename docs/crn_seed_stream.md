# crn_seed_stream — G3 common-random-number 4-stream proof

> Phase 0.2 (G3) deliverable. Proves the CRN pairing that lets bus_only vs
> rail-bus deltas be attributed to transport structure, not RNG drift. Quasi-real
> decision-support only — does not prove statistical sufficiency or close any gate.

## 1. The 4-stream contract (`src/scenario.py:59-65`)

`run_scenario` derives four independent RNG streams from a single `seed`, so each
compared alternative sees the **same** demand and disruption draws:

| Stream | Offset | Consumes | Created (`scenario.py`) |
|---|---|---|---|
| arrival | `seed` | per-personnel lateness (shared demand) | L59 |
| failure | `seed + 10_000` | per-edge disruption state | L60 |
| road | `seed + 20_000` | road-link travel-time noise (only if `road_noise_sigma > 0`) | L64 |
| turnaround | `seed + 30_000` | vehicle turnaround noise (only if `turnaround_noise_lambda > 0`) | L65 |

Streams 1–2 (the **common inputs** — demand + disruption) are sampled **before**
the `bus_only`/`multimodal` branch (`scenario.py:67-75`, branch at L91), so they
cannot diverge by mode. Streams 3–4 are per-mode operational noise, but each mode
re-seeds them identically from the same offsets, so the pairing stays fair.

## 3. CSV provenance column — `seed_stream_id`

Added to `RESULT_COLUMNS` and `_result_row` (`pilot_experiments.py`):
`seed_stream_id = sha256(seed|seed+10000|seed+20000|seed+30000)[:12]`.

Pure function of `seed` → a reviewer can verify CRN pairing **from the CSV alone**:
any two rows sharing `seed` (across mode/policy) share the same id, confirming the
same stream bundle. Encodes all four stream seeds, not just arrival.

`tests/test_realworld_pilot_experiments.py` and `test_realworld_sensitivity.py`
(assert `fieldnames == RESULT_COLUMNS`) still pass — the schema addition is
append-clean. Existing `results/realworld_pilot/*.csv` are now schema-stale and
are regenerated by the Phase 6 full rerun (0.7 archives the old scaffold).

## 4. The `needs_human_review` audit marker — resolved (by proof, not by weakening)
