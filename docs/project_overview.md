# 프로젝트 개요 — 2026-07-21 논문 재실험

## 목적

송파–고성 공개 코리더에서 버스 단독과 철도–버스 복합운송의 조건부 성능 경계를 비교한다. 수단 일반의 우열이 아니라 자원 프레임, 그래프 범위, 장거리 도로 감속, 철도 상태, 수요·함대, 대응정책이 결과를 바꾸는 지점을 찾는다.

공개 행정중심점과 공공 철도역만 사용한다. 실제 부대 위치·부대편제·이동일정은 포함하지 않는다. 결과는 의사결정지원용 민감도 산출물이며 `final_study_ready=false`다.

## 모형 핵심

- 버스 단독: A→D 도로 직행.
- 고정 복합운송: A→S 도로, S→R 철도, R→D 도로.
- 차량 재사용: 승객운송 → 역방향 도로망 공차회송 → 8분 회차.
- 차단: 간선 제거 후 경로 재탐색; 대체경로가 없을 때만 미완료.
- 철도 상태: 대응정책은 정상가용·1.5배 열화·사용불가; 도로–철도 지도는 1.25·2.0배 열화를 추가.
- 정책: 버스, 고정 복합, 600/400 분할, 사전확인 전환, 역 대기후 30/60/90분 전환.
- 판정: 완료율 우선, 같은 완료율에서는 유한 완료시간 최소.

## 결론

현재 근거가 지지하는 결론은 “수단 우열은 자원·망·철도·정책 조건에 따라 달라진다”이다. 1.742배는 지정 조건의 평균 경계이며 다른 코리더의 일반값이 아니다. 동일 도로차량 총수도 동일비용 비교가 아니다.
