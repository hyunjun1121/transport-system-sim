## Changes

The generator wording was narrowed while preserving the same review intent:

- The packet scope now says it does not certify sources, licenses,
  field-fit benchmark evidence, or deployment routing evidence.
- Table required actions now use `before provenance decision record` rather
  than `before acceptance`.
- Required reviewer actions now refer to `release-scope claims` rather than
  unbounded final claims.
- Review items now use `provenance decision record` rather than provenance
  acceptance where that wording appeared in generated review text.

The shipped-packet test no longer assumes the KTDB GTFS context source row is
`network_error`; the current generated rows have reachable URLs and retain 11
local artifacts. The assertion now checks the stable intent: the KTDB local
artifact set still includes `data/rail/ktdb_gtfs_source_extract.csv`.
