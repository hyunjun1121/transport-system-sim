## Changes

The packet generator now uses fail-closed review wording where it previously
used approval-like terms in generated rows:

- Missing artifact, text, and figure rows now use
  `requires_revision_or_review`.
- Markdown row status values are display-normalized, for example
  `requires_revision_or_review` becomes `requires revision or review`.
- Claim categories are display-normalized to reviewer-facing wording:
  `calibration_claim` becomes `parameter-fit wording`,
  `validation_claim` becomes `benchmark-check wording`,
  `acceptance_claim` becomes `gate-closure wording`, and
  `operational_claim` becomes `deployment wording`.
- Required action text now asks reviewers to revise or hold wording until the
  relevant reviewer gates close, without implying that any gate is closed.
- The packet summary `overclaim_candidate_count` now counts rows with
  `review_status == "requires_revision_or_review"`.

The associated unit test expected status values were updated to match the new
review wording.
