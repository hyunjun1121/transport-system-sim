## Plan Changes

`plan.md` was updated to make the multi-agent workflow more executable and less
ambiguous:

1. Added a machine-checkable wave contract before spawning agents. The contract
   records phase ID, objective, upstream gate state, model/reasoning,
   per-agent read/write scopes, forbidden paths, dependency inputs, allowed and
   forbidden commands, start/stop conditions, required output fields, required
   tests or audits, parallel-safety checks, join barrier, and self-refine
   triggers.
2. Added a parallelism pass/warn/fail rule:
   - pass when agents are read-only or write to truly disjoint path prefixes;
   - warn and split when semantic dependencies exist;
   - fail and block when paths overlap, an audit races a writer, conclusions
     are chained without main-thread inspection, or cleanup is proposed outside
     an approved restore workflow.
3. Added default GPT-5.5 xhigh personas:
   - transportation systems researcher;
   - public-data provenance auditor;
   - simulation engineer;
   - statistical reviewer;
   - GPU/performance reviewer;
   - adversarial claim-boundary reviewer.
4. Added the Wave 3 self-refine micro-cycle for blocker/high findings:
   numbered fix ticket, narrow patch only, smallest proving command first,
   changed-path comparison, same-role or stricter recheck, and blocking after
   repeated unresolved blocker.
5. Updated hardware evidence commands to use a supported `nvidia-smi` query and
   explicitly avoid relying on unsupported `cuda_version` query fields.
